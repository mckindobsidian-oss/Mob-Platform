Mob for Windows

One setup file. Your full desktop workspace.

Download for WindowsWindows x64 · v1.5.1 · unsigned test build
How to install

Quit any older Mob from its tray. Run the setup file; it installs for your Windows account and adds shortcuts. This build is unsigned.

♧

Mob for Android

Your tasks and focus, in your pocket.

Download Android APKAndroid 8+ · v1.5.1 · debug-signed test build
How to install

Install the APK using Android's install permission. Enable Accessibility only if you want YouTube Shorts blocking. Physical-device verification is still pending.

◎

Mob browser extension

Track the tab you use. Block the distractions.

Download extensionChrome / Edge · v1.6.2 · unpacked extension
How to install

Extract the ZIP. Open your browser's Extensions page, enable Developer mode and choose Load unpacked. Then sign in to Mob and link the browser in Flow.
